# 数据结构

JavaScript 是动态弱类型语言，没有传统意义上的"数据结构类型"，而是通过**基本类型 + 引用类型 + 内建集合对象**组合出常用的数据结构能力。

## 集合类型

### Array（数组）

有序列表，本质是对象，索引即属性名。JS 数组是动态的、可稀疏的。

```js
const arr = [1, 2, 3];
arr.push(4);        // 尾部插入
arr.unshift(0);     // 头部插入
arr.splice(1, 1);   // 任意位置删除
```

### Map（键值对）

与普通对象的区别：**键可以是任意类型**、保持插入顺序、可直接获取大小、键的数量可枚举。

```js
const map = new Map();
map.set({ id: 1 }, "对象也可以作键");
map.set(1, "数字键");
map.has(1);         // true
map.size;           // 2
```

### Set（去重集合）

成员唯一，常用于去重和存在性判断。

```js
const set = new Set([1, 2, 2, 3]);  // {1, 2, 3}
[...new Set(arr)];                  // 数组去重的惯用法
```

### WeakMap / WeakSet

键为弱引用，不阻止垃圾回收，适合给对象挂附加信息而不影响其生命周期（如 DOM 节点缓存、私有数据）。

```js
const cache = new WeakMap();
cache.set(domNode, { clicks: 0 });  // domNode 被移除后缓存自动可回收
```
