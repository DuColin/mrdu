# 双向链表

双向链表（Doubly Linked List）的每个节点包含三个部分：`prev` 指向前驱节点、`next` 指向后继节点、以及存储的数据。相比[单向链表](./单向链表.md)，它可以双向遍历，删除已知节点时无需从头查找前驱。

## 与单向链表的对比

| 操作 | 单向链表 | 双向链表 |
| --- | --- | --- |
| 头部插入/删除 | O(1) | O(1) |
| 尾部插入/删除 | O(n)（需遍历，若维护尾指针则 O(1)） | O(1)（维护尾指针） |
| 已知节点删除前驱 | O(n) | O(1) |
| 空间开销 | 每节点 1 个指针 | 每节点 2 个指针 |

## JavaScript 实现

```js
class Node {
    constructor(value) {
        this.value = value;
        this.prev = null;
        this.next = null;
    }
}

class DoublyLinkedList {
    constructor() {
        this.head = null;
        this.tail = null;
        this.size = 0;
    }

    /** 尾部插入 O(1) */
    append(value) {
        const node = new Node(value);
        if (!this.head) {
            this.head = this.tail = node;
        } else {
            node.prev = this.tail;
            this.tail.next = node;
            this.tail = node;
        }
        this.size++;
    }

    /** 头部插入 O(1) */
    prepend(value) {
        const node = new Node(value);
        if (!this.head) {
            this.head = this.tail = node;
        } else {
            node.next = this.head;
            this.head.prev = node;
            this.head = node;
        }
        this.size++;
    }

    /** 删除第一个匹配值的节点 O(n) */
    remove(value) {
        let cur = this.head;
        while (cur) {
            if (cur.value === value) {
                if (cur.prev) cur.prev.next = cur.next;
                else this.head = cur.next;
                if (cur.next) cur.next.prev = cur.prev;
                else this.tail = cur.prev;
                this.size--;
                return true;
            }
            cur = cur.next;
        }
        return false;
    }

    /** 正向遍历 */
    toArray() {
        const result = [];
        let cur = this.head;
        while (cur) {
            result.push(cur.value);
            cur = cur.next;
        }
        return result;
    }

    /** 反向遍历 */
    toArrayReversed() {
        const result = [];
        let cur = this.tail;
        while (cur) {
            result.push(cur.value);
            cur = cur.prev;
        }
        return result;
    }
}
```

## 实现要点

1. **边界情况**：空链表、头节点、尾节点的插入/删除都要单独处理，尤其是 `head` 和 `tail` 指针的同步更新。
2. **删除节点**：改完 `cur.prev.next` 和 `cur.next.prev` 后，别忘了更新 `head`/`tail`。
3. **哨兵节点（dummy head/tail）**：使用虚拟头尾节点可以消除大部分边界判断，是工程实现的首选写法。
4. **环检测**：双向链表实现不当容易出现 `prev`/`next` 指向自身形成环，调试时可以打印遍历步数上限来排查。
