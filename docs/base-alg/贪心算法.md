# 贪心算法

## 题目

### 1. 分糖果问题

##### 描述

一群孩子做游戏，现在请你根据游戏得分来发糖果，要求如下：

1. 每个孩子不管得分多少，起码分到一个糖果。
2. 任意两个相邻的孩子之间，得分较多的孩子必须拿多一些糖果。(若相同则无此限制)

给定一个数组  $arr$ 代表得分数组，请返回最少需要多少糖果。

要求: 时间复杂度为 $O(n)$，空间复杂度为 $O(n)$


数据范围： $1 ≤ n ≤ 100000$，$1 ≤ a_i ≤ 1000$


- **示例 1**
```
输入：[1,2,2]
返回值：4
说明：最优分配方案为1,1,2
```
- **示例 2**
```
输入：[1,1,1]
返回值：3
说明：最优分配方案是1,1,1 
```

##### 题解


**代码实现**

```typescript
/**
 * 代码中的类名、方法名、参数名已经指定，请勿修改，直接返回方法规定的值即可
 *
 * pick candy
 * @param arr int整型一维数组 the array
 * @return int整型
 */
export function candy(arr: number[]): number {
    const n = arr.length;
    if (n <= 1) return n;

    // 1. 初始化糖果数组，并确保每个孩子能分到一个糖果
    const suggerArr = new Array(n).fill(1)

    // 2. 从左向右遍历，确保右边得分高的孩子，比左边得分高的孩子糖果多
    for (let i = 1; i < n; i += 1) {
        if (arr[i] > arr[i-1]) {
            suggerArr[i] = suggerArr[i-1] + 1;
        }
    }

    // 2. 从右往左遍历，确保左边得分比右边得分比右边得分高的孩子糖果多
    for (let i = n - 2; i >= 0; i -= 1) {
        if (arr[i] > arr[i + 1]) {
            // 这里必须取最大值，因为 candies[i] 可能已经在上一轮被更新得很大了
            suggerArr[i] = Math.max(suggerArr[i], suggerArr[i + 1] + 1); 
        }
    }

    // 计算总糖果数量
    return suggerArr.reduce((sum, count) => sum + count, 0);
}
```
