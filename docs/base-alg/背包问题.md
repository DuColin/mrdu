# 背包问题

## 详解

背包问题是动态规划的经典场景：有 n 件物品和一个容量为 V 的背包，第 i 件物品重量为 w_i、价值为 v_i，求如何选取物品，使装入背包的物品总价值最大。

常见变体：

| 类型 | 物品数量 | 一维 DP 容量遍历顺序 |
| --- | --- | --- |
| 0-1 背包 | 每件只能选一次 | **倒序** |
| 完全背包 | 每件可选无限次 | **正序** |
| 多重背包 | 每件有数量上限 | 按数量拆分后同 0-1 背包 |

**状态定义**：$dp[j]$ 表示背包容量为 $j$ 时能获得的最大价值。

**状态转移方程**（0-1 背包）：

$$dp[j] = \max(dp[j],\ dp[j - w_i] + v_i)$$

倒序遍历是为了保证每件物品只被选一次；如果正序遍历，$dp[j - w_i]$ 可能已经包含了当前物品，相当于同一件物品被放了多次（这正是完全背包的解法）。

## 题目

### 1. 0-1 背包

##### 描述

有 $n$ 件物品和一个容量为 $V$ 的背包。第 $i$ 件物品的重量为 $weights[i]$、价值为 $values[i]$，每件物品最多选一次，求能装入背包的物品的最大总价值。

数据范围：$1 ≤ n ≤ 100$，$1 ≤ V ≤ 10^3$，$1 ≤ w_i, v_i ≤ 10^3$

- **示例 1**
```
输入：V = 5, weights = [1, 2, 3], values = [6, 10, 12]
返回值：22
说明：选第 2、3 件物品，总重量 2 + 3 = 5，总价值 10 + 12 = 22
```

##### 题解

**代码实现**

```typescript
/**
 *
 * @param V int整型 背包容量
 * @param weights int整型一维数组 物品重量
 * @param values int整型一维数组 物品价值
 * @return int整型
 */
export function knapsack(V: number, weights: number[], values: number[]): number {
    // dp[j]：容量为 j 时的最大价值
    const dp = new Array(V + 1).fill(0);

    for (let i = 0; i < weights.length; i += 1) {
        // 0-1 背包必须倒序遍历，保证每件物品只选一次
        for (let j = V; j >= weights[i]; j -= 1) {
            dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }

    return dp[V];
}
```

### 2. 分割等和子集

##### 描述

给定一个只包含正整数的非空数组 $nums$，判断能否把数组分割成两个子集，使两个子集的元素和相等。

等价于：能否从数组中选出一些数，使它们的和恰好等于数组总和的一半，典型的 0-1 背包应用。

数据范围：$1 ≤ nums.length ≤ 200$，$1 ≤ nums[i] ≤ 100$

- **示例 1**
```
输入：[1, 5, 11, 5]
返回值：true
说明：可以分割成 [1, 5, 5] 和 [11]
```
- **示例 2**
```
输入：[1, 2, 3, 5]
返回值：false
说明：数组总和为 11，无法分割成两个和相等的子集
```

##### 题解

转化为 0-1 背包：背包容量为 $sum / 2$，物品重量和价值均为 $nums[i]$，判断能否恰好装满背包。

**代码实现**

```typescript
/**
 *
 * @param nums int整型一维数组
 * @return bool布尔型
 */
export function canPartition(nums: number[]): boolean {
    const sum = nums.reduce((a, b) => a + b, 0);

    // 总和为奇数，不可能平分
    if (sum % 2 !== 0) return false;

    const target = sum / 2;

    // dp[j]：容量为 j 时能凑出的最大和
    const dp = new Array(target + 1).fill(0);

    for (let i = 0; i < nums.length; i += 1) {
        for (let j = target; j >= nums[i]; j -= 1) {
            dp[j] = Math.max(dp[j], dp[j - nums[i]] + nums[i]);
        }
    }

    return dp[target] === target;
}
```

### 3. 零钱兑换（完全背包）

##### 描述

给定不同面额的硬币数组 $coins$ 和总金额 $amount$，每种硬币数量无限，计算凑成总金额所需的最少硬币数。如果无法凑出，返回 $-1$。

数据范围：$1 ≤ coins.length ≤ 20$，$1 ≤ coins[i] ≤ 10^4$，$0 ≤ amount ≤ 10^4$

- **示例 1**
```
输入：coins = [1, 2, 5], amount = 11
返回值：3
说明：11 = 5 + 5 + 1
```
- **示例 2**
```
输入：coins = [2], amount = 3
返回值：-1
```

##### 题解

完全背包：每件物品可选无限次，容量正序遍历。求"最少"方案数，转移时取 $min$。

**代码实现**

```typescript
/**
 *
 * @param coins int整型一维数组 硬币面额
 * @param amount int整型 总金额
 * @return int整型
 */
export function coinChange(coins: number[], amount: number): number {
    // dp[j]：凑出金额 j 所需的最少硬币数
    const dp = new Array(amount + 1).fill(Infinity);
    dp[0] = 0;

    for (const coin of coins) {
        // 完全背包：正序遍历，允许重复选取同一面额
        for (let j = coin; j <= amount; j += 1) {
            if (dp[j - coin] !== Infinity) {
                dp[j] = Math.min(dp[j], dp[j - coin] + 1);
            }
        }
    }

    return dp[amount] === Infinity ? -1 : dp[amount];
}
```
