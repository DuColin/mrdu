
# 字符串

## 字符串翻转

### 业务场景

字符串翻转不只是算法题，在真实业务中很常见：

- **大数运算**：超出 `Number.MAX_SAFE_INTEGER` 的超大整数按字符串计算加减法时，需要先翻转让个位对齐，从低位向高位计算进位。
- **回文校验**：防伪码、流水号等合法性校验，翻转后与原串比较即可判断是否回文。
- **倒序展示**：聊天记录、日志查看器按时间倒序渲染，本质是对序列做翻转。
- **格式转换**：部分定长报文字段（如日期 `20231122` 转为 `22-11-2023`）的展示，本质是分段翻转重排。

### 实现方式

**方式 1：数组方法（日常首选）**

```typescript
function reverseString(s: string): string {
    return s.split('').reverse().join('');
}
```

**方式 2：双指针交换（面试常考）**

JS 字符串不可变，先转字符数组，两端向中间交换。时间复杂度 $O(n)$，空间复杂度 $O(n)$。

```typescript
function reverseString(s: string): string {
    const arr = s.split('');

    let left = 0;
    let right = arr.length - 1;

    while (left < right) {
        [arr[left], arr[right]] = [arr[right], arr[left]];
        left += 1;
        right -= 1;
    }

    return arr.join('');
}
```

**方式 3：倒序拼接**

从尾部向头部遍历，逐个累加。

```typescript
function reverseString(s: string): string {
    let result = '';

    for (let i = s.length - 1; i >= 0; i -= 1) {
        result += s[i];
    }

    return result;
}
```

**方式 4：递归**

每次取首字符挪到末尾。递归深度为 $n$，长字符串会栈溢出，仅适合用来理解递归思想。

```typescript
function reverseString(s: string): string {
    if (s.length <= 1) return s;

    return reverseString(s.slice(1)) + s[0];
}
```

**注意：Unicode 代理对问题**

`split('')` 按 UTF-16 码元切分，emoji 或生僻字（如 `𠮷`）由两个码元组成，直接翻转会产生乱码。需要按**码点**切分：

```typescript
function reverseStringSafe(s: string): string {
    // 展开运算符按码点切分，emoji 不会被拆坏
    return [...s].reverse().join('');
}
```

```typescript
 *
 * 
 * @param s string字符串 
 * @param n int整型

export function trans(s: string, n: number): string {
     // 1. 把字符串分割为字符
    let letterArr = s.split('');

    // 2. 字母反转
    letterArr = letterArr.map(le => {
        if (/^[a-z]$/.test(le)) {
            return le.toUpperCase();
        } else if (/^[A-Z]$/.test(le)) {
            return le.toLowerCase();
        } 
        return le;
    })

    // 3. 把反转字母拼接回来
    s = letterArr.join('')

    // 4. 把单词反序
    s = s.split(' ').reverse().join(' ');

    return s
}
```

```typescript
/**
 * 代码中的类名、方法名、参数名已经指定，请勿修改，直接返回方法规定的值即可
 *
 * 
 * @param strs string字符串一维数组 
 * @return string字符串
 */
export function longestCommonPrefix(strs: string[]): string {
    // 1. 处理边界情况
    if (!strs.length) return '';

    // 2. 如果只有一个字符串，说明第一个字符串就是公共子串
    if (strs.length === 1) return strs[0];

    // 3. 以第一个字符串作为标杆查找公共子串
    const firstStr = strs[0];
    for (let i = 0; i < firstStr.length; i += 1) {
        const char = firstStr[i];

        // 第一个字符串是标杆，不需要匹配了
        for (let j = 1; j < strs.length; j +=1 ) {
            
            // 1. 如果i位置的字符不相同，说明匹配完了
            if (i === strs[j].length || char !== strs[j][i]) {
                return firstStr.substring(0, i);
            }
        }
    }

    // 4. 如果全都执行完了，说明全部匹配上了
    return firstStr;
}
```
