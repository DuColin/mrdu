JS 是如何看待二进制的？

在讲解操作符之前，必须先明白 JavaScript 的底层机制：

  1. 底层存储：JavaScript 中的所有数字默认都是以 64 位浮点数（IEEE 754 标准） 格式存储的。
  2. 位运算转换： 当对一个数字进行位运算时，JS 引擎会临时将这个 64 位浮点数转换为 32 位有符号整数（32-bit signed integer）。
  3. 最高位（符号位）：这 32 位中，第 31 位（最高位）是符号位。0 表示正数，1 表示负数。
  4. 负数的表示（补码）：JS 使用补码（Two's Complement）来表示负数。负数的二进制 = 其绝对值的反码 + 1。

位操作符是什么？

位操作符是是写在高级语言里、却能直接插手计算机底层心脏的“黑魔法”。

JS 一共提供了 7 种位操作符，可以分为两类：位逻辑操作符和移位操作符。

为了方便演示，我们用 8 位二进制（实际在底层是 32 位）来举例，假设：

  • A = 5（二进制：0000 0101）
  • B = 3（二进制：0000 0011）

位逻辑操作符

  • 按位与 &

    • 规则：只要对应的两个二进位中有一个为 1，结果位就为 1。
    • 数学推导：
      text
      A = 5  ->  0000 0101
B = 3  ->  0000 0011
--------------------
A & B  ->  0000 0001  （十进制结果为 1）
    • 代码示例：
      js
      const result = 5 & 3;
console.log(result); // 输出: 1

  • 按位或 |

    • 规则：只要对应的两个二进位中有一个为 1，结果位就为 1。
    • 数学推导：
      text
      A = 5  ->  0000 0101
B = 3  ->  0000 0011
--------------------
A | B  ->  0000 0111  （转换为十进制结果为 7）
    • 代码示例：
      js
      const result = 5 | 3;
console.log(result); // 输出: 7

  • 按位非 ~

    • 规则: 一元操作符。将操作数的每一位无脑取反（0 变成 1，1 变成 0）。
    • 数学推导：
      text
      A = 5  ->  0000 0101
--------------------
~A  ->  1111 1010  （转换为十进制结果为 -6）
    • 代码示例：
      js
      console.log(~5);  // 输出: -6
console.log(~-1); // 输出: 0 （因为 -(-1 + 1) = 0）

  • 按位异或 ^

    • 规则：对应的两个二进位不相同时，结果位为 1；如果相同（同为 0 或同为 1）则为 0。
    • 数学本质：对任一数值 x 进行 ~x 运算，其结果在数学上始终等于 −(x+1)。
    • 数学推导：
      text
      A = 5  ->  0000 0101
B = 3  ->  0000 0011
--------------------
A ^ B  ->  0000 0110  （转换为十进制结果为 6）
    • 代码示例：
      js
      const result = 5 ^ 3;
console.log(result); // 输出: 6

移位操作符

  • 左移 <<

    • 规则：将数字的二进制表示向左移动指定的位数。右侧空出的位用 0 填充，左侧溢出的位被丢弃。
    • 数学本质：符号位保持不变，负数左移后依然是负数，只要没有溢出，左移 n 位就等价于乘以 2n。。
    • 数学推导：
      text
      A = 5   ->  0000 0101
---------------------
A << 1  ->  0000 1010  （十进制结果为 10，即 5 * 2）
    • 代码示例：
      js
      console.log(5 << 1); // 输出: 10
console.log(5 << 3); // 输出: 40 (5 * 2^3)

  • 有符号右移 >>

    • 规则： 将数字向右移动指定位数。右侧溢出的位被丢弃，左侧空出的位用原来的符号位填充（正数补 0，负数补 1）。
    • 数学本质：符号位保持不变，负数右移后依然是负数，只要没有溢出，右移 n 位就等价于除以 2n 并向下取整。
    • 数学推导：
      text
      A = 5   ->  0000 0101
---------------------
A >> 1  ->  0000 0010  （十进制结果为 2）
    • 代码示例：
      js
      console.log(5 >> 1);

  • 无符号右移 >>>
